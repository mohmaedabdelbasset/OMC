Irreducibility: Gauss, Eisenstein and Rabin

Click any card to open its full proof and worked example.

Goal: decide whether f(x) factors into polynomials of smaller degree over ℤ[x] or ℤp[x].

Intuition. The content of a polynomial is the gcd of its coefficients. It is primitive when its content is 1. Gauss’s Lemma: a primitive polynomial is irreducible over ℤ exactly when it is irreducible over ℚ.

Example 1 – not primitive f(x) = 4x² + 2 = 2 · (2x² + 1) content(f) = gcd(4, 0, 2) = 2 → NOT primitive The factor 2 is not a unit, so f is reducible over ℤ. Example 2 – primitive g(x) = 6x² + 5x + 1 content(g) = gcd(6, 5, 1) = 1 → primitive (2x + 1)(3x + 1) = 6x² + 2x + 3x + 1 = 6x² + 5x + 1 → reducible over ℤ and over ℚ, as the lemma predicts

Statement. Let f = aₙxⁿ + … + a₀ ∈ ℤ[x]. If a prime p satisfies (1) p ∤ aₙ, (2) p | aᵢ for every i < n, and (3) p² ∤ a₀, then f is irreducible over ℚ.

Coefficients: a₅ = 1, a₄ = 0, a₃ = 0, a₂ = 0, a₁ = 2, a₀ = 2
ConditionCheckResult
(1) p ∤ a₅2 ∤ 1✓
(2) p | a₄2 | 0✓
(2) p | a₃2 | 0✓
(2) p | a₂2 | 0✓
(2) p | a₁2 | 2✓
(2) p | a₀2 | 2✓
(3) p² ∤ a₀4 ∤ 2✓

Conclusion: all conditions hold, so f is irreducible. Its content is gcd(1, …) = 1, so it is also irreducible over ℤ.

Why it works

Suppose f = g·h with deg g, deg h ≥ 1. Reducing mod 2 gives x⁵ ≡ g·h, so g ≡ xʳ and h ≡ xˢ with r, s ≥ 1. Both constant terms are then even, so 4 divides a₀ = 2, a contradiction.

Statement. f of degree n over 𝔽p is irreducible iff x^(pⁿ) ≡ x (mod f) and gcd(x^(p^(n/q)) − x, f) = 1 for every prime q dividing n.

Setup: n = 2, p = 3. The only prime dividing n is q = 2. Step 1 – check x⁹ ≡ x (mod f), where x² ≡ −1 = 2 x³ = x · x² = −x x⁹ = (x³)³ = (−x)³ = −x³ = −(−x) = x ⇒ x⁹ ≡ x (mod f) ✓ Step 2 – check gcd(x^(3^(n/q)) − x, f) with n/q = 1 x³ − x = −x − x = −2x ≡ x (mod 3) gcd(x, x² + 1) = 1 (x does not divide x² + 1, since its constant term is 1 ≠ 0) ✓

Conclusion: both conditions hold, so x² + 1 is irreducible over 𝔽₃. Cross-check: the squares mod 3 are 0 and 1, and −1 ≡ 2 is not one of them, so there is no root.

Eisenstein needs a prime p dividing a₀. For f(x) = x² + 1 we have a₀ = 1, and 1 has no prime divisor, so the criterion is silent for every prime.

Eisenstein on x² + 1: a₀ = 1 → no prime p | 1 → criterion FAILS Real roots of x² + 1: none → degree 2 with no rational root → irreducible over ℚ (and over ℤ, it is primitive) Rabin over 𝔽₃: x² + 1 is irreducible mod 3 (previous card)

Why Rabin is essential: if f mod p is irreducible and p does not divide the leading coefficient, then f is irreducible over ℤ. Rabin’s test can certify irreducibility in cases where Eisenstein says nothing.

check_irreducible_Z(f): builds a SymPy polynomial over ℤ, calls factor_list(), and returns True only when exactly one factor appears, with multiplicity 1 and degree ≥ 1.

check_irreducible_Zp(f, p): the same test in ℤp[x], using a polynomial with modulus=p.

rabin_test(f, p): stores f as a coefficient list mod p and runs two modular computations:

x^(p^k) mod f → gf_pow_mod(X, p**k, f, p) square-and-multiply: about log₂(p^k) squarings gcd(x^(p^(n/q)) − x, f) → gf_gcd(f, h, p) (Euclid on polynomials)

For x² + 1 with p = 3: the exponent 9 = 1001₂ is processed bit by bit, so x⁹ is reached with a few squarings and multiplications by x, always reduced mod f.

AES works in 𝔽₂⁸ = ℤ₂[x] / (x⁸ + x⁴ + x³ + x + 1). That modulus is irreducible, so every nonzero byte has an inverse, which the S-box needs.

Éléments primitifs de 𝔽q*

Cliquez sur une carte pour voir la démonstration et le calcul complet.

g ∈ 𝔽q* est primitif si ⟨g⟩ = 𝔽q*, c’est-à-dire si l’ordre de g est q − 1. Exemple dans 𝔽₇* (q − 1 = 6) :

g = 3 : 3¹=3 3²=2 3³=6 3⁴=4 3⁵=5 3⁶=1 → ordre 6 = q − 1 ⇒ 3 est PRIMITIF ✓ g = 2 : 2¹=2 2²=4 2³=1 → ordre 3 < 6 ⇒ 2 n’est PAS primitif ✗

Ici q − 1 = 6, ses diviseurs premiers sont r = 2 et r = 3.

g = 3 : 3^(6/2) = 3³ = 6 ≠ 1 ✓ 3^(6/3) = 3² = 2 ≠ 1 ✓ ⇒ primitif g = 2 : 2^(6/2) = 2³ = 1 ✗ ⇒ non primitif (un seul échec suffit)

Énoncé : si G est un groupe fini, l’ordre de tout élément de G divise |G|.

Application à 𝔽₇* (|G| = 6) Les ordres possibles sont 1, 2, 3, 6. Exemple : g = 4 : 4¹=4 4²=2 4³=1 → ordre 3, et 3 | 6 ✓

Pourquoi cela justifie le critère : si l’ordre d de g est un diviseur propre de 6, alors d | 3 ou d | 2, donc d divise 6/2 = 3 ou 6/3 = 2. Tester r = 2 et r = 3 suffit.

Énoncé : 𝔽q* étant cyclique, il existe exactement φ(q − 1) éléments primitifs.

φ(6) = 6 · (1 − 1/2) · (1 − 1/3) = 6 · 1/2 · 2/3 = 2 Éléments primitifs de 𝔽₇* : {3, 5} Vérification de 5 : 5¹=5 5²=4 5³=6 5⁴=2 5⁵=3 5⁶=1 → ordre 6 = q − 1 ⇒ 5 est primitif ✓

Exemple complet : 𝔽₉ = 𝔽₃[x] / (x² + 1)

Tout le test se vérifie à la main, avec un contre-exemple.

Construction : x² + 1 est irréductible sur 𝔽₃, car −1 ≡ 2 n’est pas un carré modulo 3. Donc 𝔽₉ = {a + bx : a, b ∈ 𝔽₃}, avec x² = −1 = 2.

α = x + 1 α² = x² + 2x + 1 = (x² + 1) + 2x = 2x α³ = α² · α = 2x(x + 1) = 2x² + 2x = 4 + 2x = 1 + 2x α⁴ = (α²)² = (2x)² = 4x² = x² = 2 α⁵ = 2(x + 1) = 2x + 2 α⁶ = (α³)² = (1 + 2x)² = 1 + 4x + 4x² = 1 + x + 2 = x α⁷ = x(x + 1) = x² + x = 2 + x α⁸ = (α⁴)² = 2² = 4 = 1

Les huit valeurs α¹ … α⁸ sont toutes distinctes et non nulles, donc elles parcourent 𝔽₉*.

q − 1 = 8 = 2³, le seul premier à tester est r = 2, donc il suffit de calculer α^((9−1)/2) = α⁴.

α^4 = 2 ≠ 1 ✓ ⇒ α = x + 1 est PRIMITIF (ordre 8) Contre-exemple : 2 ∈ 𝔽₃ ⊂ 𝔽₉ 2^4 = (2²)² = 1² = 1 ✗ ⇒ 2 n’est PAS primitif (son ordre est 2)

Vérification du nombre : φ(8) = 4. Les éléments primitifs sont exactement les puissances impaires de α : α, α³, α⁵, α⁷ = x + 1, 1 + 2x, 2x + 2, 2 + x.

Pourquoi les éléments primitifs comptent en cryptographie

Cliquez pour voir les calculs.

ElGamal : le même générateur g sert au chiffrement, et l’inversion repose sur la structure de groupe.

Paramètres publics : p = 23, g = 5. Vérification de la primitivité : q − 1 = 22 = 2 · 11, donc 5² ≠ 1 et 5¹¹ ≠ 1.

5² = 2 5³ = 10 5⁶ = 10² = 100 ≡ 8 5⁵ = 20, 5¹¹ = 5⁶ · 5⁵ = 8 · 20 = 160 ≡ −1 ≠ 1 ✓ (donc g = 5 est primitif) 5¹² ≡ −5 ≡ 18, 5¹⁵ = 5¹² · 5³ = 18 · 10 = 180 ≡ 19 Échange Alice : a = 6 A = 5⁶ ≡ 8 (envoyé à Bob) Bob : b = 15 B = 5¹⁵ ≡ 19 (envoyé à Alice) Clé d’Alice : B⁶ = 19⁶ : 19² ≡ 16, 19³ ≡ 16·19 = 304 ≡ 5, 19⁶ ≡ 5² = 25 ≡ 2 Clé de Bob : A¹⁵ = 8¹⁵ : 8² ≡ 18, 8⁴ ≡ 2, 8⁸ ≡ 4 8¹⁵ = 8⁸ · 8⁴ · 8² · 8 ≡ 4 · 2 · 18 · 8 ≡ 2 Clé commune = 2 ✓

Un espion qui connaît p, g, A et B doit résoudre 5^a ≡ 8 (mod 23), c’est-à-dire calculer un logarithme discret. Avec p = 23 c’est facile, mais des tailles réelles le rendent infaisable.

Pourquoi : si p − 1 = 2q, les seuls premiers qui divisent p − 1 sont 2 et q. Il suffit donc de tester g² ≠ 1 et g^q ≠ 1, au lieu de tester tous les diviseurs.

p = 23 = 2 · 11 + 1, q = 11 (premier) g = 5 : 5² = 2 ≠ 1 ✓ 5¹¹ = −1 ≠ 1 ✓ ⇒ primitif

Lien avec la sécurité : si p − 1 n’a que de petits facteurs premiers, l’attaque de Pohlig–Hellman casse le logarithme discret rapidement. Le choix d’un premier sûr l’empêche.

From an irreducible polynomial to a field

Irreducibility gives the field; primitive elements give its generator.

English (Nehari)

x³ + x + 1 is irreducible over ℤ2, so ℤ2[x] / (x³ + x + 1) is a field with 8 elements. Let α be the class of x.

Français (Chaib)

Ce corps est 𝔽₈, et 𝔽₈* est cyclique d’ordre 7, premier. Chaque élément non nul différent de 1 est donc primitif.

α³ = α + 1
α⁴ = α² + α
α⁵ = α² + α + 1
α⁶ = α² + 1
α⁷ = 1          → order 7 = 8 − 1
Cybersecurity relevance · Pertinence pour la cybersécurité

Why this matters for security

The mathematics is only as strong as its parameter choices.

English

AES and the field: the S-box inverts each byte in GF(2⁸). If the modulus polynomial were reducible, nonzero bytes could multiply to zero, inverses would fail, and the cipher would break.

Discrete logarithm: Diffie–Hellman security rests on the difficulty of recovering a from ga mod p. Real deployments use primes of at least 2048 bits.

Français

Pohlig–Hellman : si p − 1 n’a que de petits facteurs premiers, le logarithme discret se casse rapidement. D’où le choix de p = 2q + 1 avec q premier.

Générateur faible : si g a un ordre petit, la clé est confinée à un petit sous-groupe et peut être devinée. Vérifier que g est primitif évite ce piège.

Card 1 · EnglishIf f mod p is irreducible over ℤp and p does not divide the leading coefficient, must f be irreducible over ℤ? Is the converse true?Click to flip
AnswerYes for the first part: such an f is irreducible over ℤ. The converse is false: x⁴ + 1 is irreducible over ℤ, but it is reducible modulo every prime. Eisenstein’s criterion can only prove irreducibility; if it fails, nothing is decided.
Carte 2 · FrançaisQuelle condition caractérise un élément primitif g de 𝔽p* ?Cliquez pour retourner
Réponseg est primitif ssi son ordre est p − 1, c’est-à-dire ssi g(p−1)/r ≢ 1 (mod p) pour chaque diviseur premier r de p − 1. Exemple : p = 7, pour g = 3, 3² ≡ 2 et 3³ ≡ 6, donc 3 est primitif.
Carte 3 · FrançaisQuelle est la complexité de la recherche des racines primitives, et pourquoi factoriser p − 1 aide-t-il ?Cliquez pour retourner
RéponseMéthode naïve : calculer toutes les puissances de chaque candidat, soit environ O(p²) multiplications. Avec la factorisation de p − 1 : chaque candidat coûte ω(p − 1) exponentiations modulaires en O(log p) multiplications, soit environ O(p · ω(p−1) · log p) au total.
